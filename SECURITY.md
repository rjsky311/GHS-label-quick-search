# Security Policy

## Supported version

Security fixes target the current `main` branch and the production deployment.
Older commits, local forks, and prototype deployments are not supported.

## Report a vulnerability privately

Do not open a public GitHub issue for a suspected vulnerability, exposed
credential, or private lab data. Use GitHub's private vulnerability reporting
form instead:

https://github.com/rjsky311/GHS-label-quick-search/security/advisories/new

Include the affected URL or component, reproduction steps, expected impact,
and a minimal proof. Do not include live admin keys, credentials, personal
data, confidential inventory, or unnecessary SDS/workbook contents. The
maintainer will acknowledge the report through the private advisory and use
that thread for remediation and disclosure coordination.

Public data-quality corrections that are not security issues should continue
to use the repository's data-correction issue form.
